# Growva Smart Farming Frontend

React + Vite + Framer Motion + Lucide React frontend prototype.

## Run
```bash
npm install
npm run dev
```

## Included
- Mouse-reactive 3D/parallax robot hero using the supplied robotic-farm image.
- Farmer dashboard / smart farming landing page.
- Planner with sowing-to-harvest timeline and irrigation recommendation.
- Weather section with forecast, rainfall, humidity, wind and alert UI.
- Crop library with 120+ produce profiles across crops, pulses, vegetables, fruits and spices.
- Real-image crop cards via remote image sources with fallback.
- Schemes & subsidy discovery cards.
- 22 Indian scheduled-language options in the language selector.
- Responsive desktop/tablet/mobile layout.

This is a frontend prototype. Connect real weather, mandi, government scheme, voice and AI-diagnosis APIs for production data.
